# 音域（YINYU）音乐平台 - 项目介绍文档

## 一、项目概述

**音域（YINYU）** 是一款面向音乐爱好者的一站式在线音乐流媒体平台，致力于为用户提供高品质的音乐发现、播放、收藏与管理体验。平台涵盖前端用户展示与后台管理两大核心系统，通过精致的用户界面与强大的数据运营能力，打造沉浸式的音乐服务生态。

## 二、项目定位

- **目标用户**：音乐爱好者、独立音乐人、数字音乐消费者
- **核心价值**：发现好音乐、享受高品质音质、个性化音乐推荐
- **平台特色**：深色沉浸式设计、Hi-Res高品质音乐专区、精准个性化推荐

## 三、系统架构

本项目由两大核心系统组成：

### 3.1 用户端（前台）
面向终端用户的音乐消费平台，提供音乐发现、播放、收藏、下载等核心功能。

### 3.2 管理端（后台）
面向平台运营人员与管理员的内容管理与数据运营平台，支撑平台的日常运营与决策分析。

## 四、核心功能模块

### 4.1 用户端功能

| 模块 | 功能描述 |
|------|----------|
| **发现页** | 个性化推荐、每日推荐、新歌速递、热门歌单 |
| **音乐播放** | 支持标准与Hi-Res高品质音频播放，提供播放控制、进度拖拽、音量调节 |
| **歌单管理** | 创建、收藏、管理系统歌单与用户自定义歌单 |
| **排行榜** | 多维度榜单（热歌榜、新歌榜、原创榜、飙升榜） |
| **电台** | 主题电台、场景化音乐推荐 |
| **会员中心** | 会员权益展示、订阅管理 |
| **搜索** | 支持音乐、歌手、专辑、歌单多维度搜索 |

### 4.2 管理端功能

| 模块 | 功能描述 |
|------|----------|
| **数据看板** | 核心指标实时监控（播放量、用户数、会员数、收益） |
| **内容管理** | 音乐、歌单、专辑、歌手、分类、版权的全生命周期管理 |
| **用户管理** | 用户列表查询、会员管理、用户等级、用户反馈处理 |
| **运营中心** | 轮播图配置、公告发布、活动管理、数据统计报表 |
| **审核系统** | 音乐内容上传审核、版权合规审查 |
| **系统管理** | 管理员权限、角色管理、操作日志审计 |

## 五、设计特色

### 5.1 视觉风格
- **深色沉浸式主题**：采用深色背景搭配高饱和度渐变，降低视觉疲劳，突出音乐内容
- **毛玻璃与卡片化设计**：提升界面层次感与现代感
- **动态Banner与轮播**：顶部大幅视觉区域，增强首屏吸引力

### 5.2 交互体验
- **即时反馈**：播放、收藏、喜欢等操作即时响应
- **实时动态**：后台管理首页实时展示用户行为动态
- **数据可视化**：趋势图、饼图、排行榜等多维度数据展示

## 六、技术栈选型

### 6.1 前端技术栈

| 技术 | 选型 | 说明 |
|------|------|------|
| **前端框架** | Vue 3 + Vite + TypeScript | Vue 3官方推荐组合，Vite构建速度极快，TypeScript提供类型安全 |
| **状态管理** | Pinia | Vue 3官方推荐，TypeScript支持极佳，API简洁直观 |
| **后台UI组件库** | Element Plus | 企业级管理后台，组件丰富，文档完善，与Vue 3深度集成 |
| **前台UI方案** | Tailwind CSS + Headless UI | 原子化CSS灵活定制，Headless UI提供无障碍基础组件，完美适配深色音乐风格 |
| **图表库** | ECharts | 功能全面，中文社区活跃，vue-echarts封装成熟 |

### 6.2 后端技术栈

| 技术 | 选型 | 说明 |
|------|------|------|
| **后端框架** | Spring Boot（Java） | 企业级后端，生态成熟，适合高并发与复杂业务场景 |
| **数据库** | MySQL 8 | 关系型数据库，事务支持好，主从复制成熟，国内生态完善 |
| **缓存** | Redis | 高性能缓存，数据结构丰富，支持持久化与集群 |
| **音频处理** | FFmpeg + JAVE2 | FFmpeg负责音频转码、提取封面、获取时长等；JAVE2为Java封装，便于Spring Boot调用 |
| **异步处理（初期）** | Spring @Async | 轻量级异步处理，适合项目初期 |
| **异步处理（后期）** | RabbitMQ | 功能完善的消息队列，可靠性高，适合复杂异步任务 |

### 6.3 基础设施

| 技术 | 选型 | 说明 |
|------|------|------|
| **文件存储（初期）** | 本地存储（`E:\yinyu-music\resource`） | 零成本，适合项目初期 |
| **文件存储（后期）** | 阿里云OSS + CDN | 稳定可靠，CDN加速，防盗链等功能完善 |
| **搜索方案（初期）** | MySQL全文索引 | 零额外成本，配置简单 |
| **搜索方案（后期）** | Elasticsearch | 全文检索能力最强，支持拼音/分词/模糊搜索，适合海量数据检索 |

## 七、技术演进规划

| 阶段 | 时间 | 技术调整 |
