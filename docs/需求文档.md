# 音域（YINYU）音乐平台 - 需求文档

## 一、文档概述

| 项目 | 内容 |
|------|------|
| **文档名称** | 音域（YINYU）音乐平台需求文档 |
| **文档版本** | v1.0 |
| **编写日期** | 2024-07-18 |
| **适用范围** | 前端开发、后端开发、UI设计、测试 |
| **前端技术栈** | Vue 3 + Vite + TypeScript + Pinia + Element Plus（后台）+ Tailwind CSS + Headless UI（前台）+ ECharts |
| **后端技术栈** | Spring Boot + MySQL 8 + Redis + FFmpeg + JAVE2 |
| **基础设施（初期）** | 本地文件存储 + MySQL全文索引 + Spring @Async |
| **基础设施（后期）** | 阿里云OSS + Elasticsearch + RabbitMQ |

## 二、用户端需求（前台）

### 2.1 全局布局

- **顶部导航栏**：包含Logo、主导航（发现、推荐、排行榜、歌单、歌手、电台、会员）、搜索框、用户头像
- **左侧边栏**：导航菜单（发现、为你推荐、私人FM、最近播放、我喜欢的音乐、下载管理）、我的歌单列表、会员中心入口
- **主内容区**：根据路由动态渲染
- **底部播放器**：全局固定播放控制栏，包含当前播放信息、播放控制按钮、进度条、音量控制
- **页脚**：网站信息、链接、社交媒体、版权声明

### 2.2 页面需求

#### 2.2.1 发现页（首页）

**Banner轮播区**
- 自动轮播，支持手动切换，指示器显示当前位置
- 展示平台活动、热门专辑、新歌首发等运营内容

**快捷入口**
- 每日推荐、歌单广场、排行榜、电台、Hi-Res专区
- 每个入口需展示对应图标与简短描述

**为你推荐**
- 横向卡片列表，展示个性化推荐歌单/专辑
- 卡片包含封面图、标题、标签描述，支持播放按钮悬浮显示

**热门歌单**
- 列表形式展示，包含序号、封面、标题、播放量
- 支持点击跳转歌单详情

**排行榜**
- 多Tab切换（热歌榜、新歌榜、原创榜、飙升榜）
- 列表展示排名、歌曲名、歌手、操作按钮

**新歌速递**
- 横向卡片布局，展示最新发布的单曲/专辑
- 卡片包含封面、标题、歌手、发行日期

#### 2.2.2 推荐页
- 基于用户收听历史与偏好的算法推荐
- 支持“不感兴趣”反馈机制

#### 2.2.3 排行榜页
- 完整的榜单分类与详情展示
- 支持按时间维度筛选（日榜、周榜、月榜）

#### 2.2.4 歌单页
- 歌单分类浏览与搜索
- 歌单详情页：封面、标题、创建者、标签、简介、歌曲列表、收藏/分享功能

#### 2.2.5 歌手页
- 歌手列表与分类筛选
- 歌手详情页：头像、简介、热门歌曲、专辑列表、相似歌手

#### 2.2.6 电台页
- 电台分类与推荐
- 电台详情与节目列表

#### 2.2.7 会员中心
- 会员权益介绍
- 订阅方案选择与支付入口

#### 2.2.8 搜索功能
- 支持关键词搜索音乐、歌手、专辑、歌单
- 搜索结果分类展示，支持筛选与排序
- 搜索历史与热门搜索推荐
- **技术实现（初期）**：基于MySQL全文索引实现基础搜索，支持模糊匹配
- **技术实现（后期）**：迁移至Elasticsearch，支持拼音搜索、分词搜索、智能纠错、搜索建议

### 2.3 播放器需求

- **基础控制**：播放/暂停、上一首/下一首、进度拖拽、音量调节
- **播放模式**：顺序播放、列表循环、单曲循环、随机播放
- **播放列表**：当前播放队列管理，支持增删改顺序
- **歌词显示**：同步歌词滚动，支持全屏歌词模式
- **音质选择**：标准、高品质、Hi-Res无损

### 2.4 用户个人中心

- **我的音乐**：最近播放、我喜欢的音乐、下载管理
- **我的歌单**：创建的歌单、收藏的歌单
- **账号设置**：头像、昵称、密码、绑定手机/邮箱

## 三、管理端需求（后台）

### 3.1 全局布局

- **侧边导航栏**：多级菜单，支持收起/展开
- **顶部栏**：面包屑导航、消息通知、用户信息下拉
- **主内容区**：各功能模块页面

### 3.2 首页（数据看板）

**核心指标卡片**
- 音乐总数、用户总数、今日播放量、付费会员数、收益（元）
- 较昨日增长/下降百分比展示

**播放量趋势图**
- 折线图展示播放量变化趋势
- 支持时间维度切换：今日、近7日、近30日、自定义
- 数据点悬浮提示具体数值

**用户来源渠道分布**
- 环形饼图展示iOS、Android、Web、小程序、其他占比
- 中心显示总用户数

**实时动态**
- 滚动列表展示最新用户行为（购买会员、收藏歌曲、注册成功、播放量突破等）
- 显示用户头像、行为描述、时间

**快捷操作**
- 图标按钮：上传音乐、添加歌单、添加歌手、用户管理、会员管理、数据统计、公告发布、系统设置

**音乐审核**
- 待审核、审核通过、审核驳回三态Tab
- 列表展示：音乐名称、歌手、上传者、提交时间、操作（通过/驳回）
- 支持查看更多

**热门歌曲TOP5**
- 排名、歌曲名、歌手、播放量

**系统公告**
- 公告标题与发布日期列表
- 支持查看更多

### 3.3 内容管理

#### 3.3.1 音乐管理
- 音乐列表：ID、名称、歌手、专辑、分类、时长、上架状态、操作
- 新增/编辑：上传音频文件（支持MP3/FLAC/WAV）、填写元数据（名称、歌手、专辑、歌词、分类、标签）
- 音频处理（FFmpeg + JAVE2）：自动提取时长、生成波形图、多音质转码（标准/高品质/Hi-Res）
- 异步处理（初期）：Spring @Async执行耗时转码任务，前台轮询任务状态
- 异步处理（后期）：RabbitMQ队列化转码任务，支持失败重试与优先级调度
- 批量操作：上架、下架、删除

#### 3.3.2 歌单管理
- 歌单列表：ID、名称、封面、创建者、歌曲数、收藏数、状态、操作
- 新增/编辑：设置名称、描述、标签、封面、添加/移除歌曲

#### 3.3.3 专辑管理
- 专辑列表：ID、名称、歌手、封面、发行日期、歌曲数、状态、操作
- 新增/编辑：设置专辑信息、关联歌曲

#### 3.3.4 歌手管理
- 歌手列表：ID、姓名、头像、性别、地区、粉丝数、状态、操作
- 新增/编辑：上传头像、填写简介、绑定歌曲与专辑

#### 3.3.5 分类管理
- 音乐分类的增删改查
- 支持多级分类

### 3.4 用户管理

#### 3.4.1 用户列表
- 列表展示：ID、头像、昵称、手机号、注册时间、最后登录、状态、操作
- 搜索筛选：按昵称、手机号、注册时间筛选
- 操作：查看详情、禁用/启用、重置密码

#### 3.4.2 会员管理
- 会员列表：用户信息、会员等级、到期时间、开通记录
- 会员配置：等级规则、权益设置

#### 3.4.3 用户等级
- 等级规则设置：经验值区间、等级名称、图标

#### 3.4.4 用户反馈
- 反馈列表：用户、类型、内容、时间、状态、操作
- 处理反馈：标记处理状态、回复用户

### 3.5 运营中心

#### 3.5.1 轮播图管理
- 轮播图列表：图片、标题、链接、排序、状态、操作
- 新增/编辑：上传图片、设置跳转链接、排序权重、有效期

#### 3.5.2 公告管理
- 公告列表：标题、类型、发布时间、状态、操作
- 新增/编辑：富文本编辑器、置顶设置、有效期

#### 3.5.3 活动管理
- 活动列表：名称、时间、状态、参与人数、操作
- 新增/编辑：活动配置、规则设置、奖品配置

#### 3.5.4 数据统计
- 用户数据：注册趋势、活跃趋势、留存分析
- 内容数据：上传量、播放量、收藏量、分享量
- 收入数据：会员收入、付费单曲、收益趋势

### 3.6 系统管理

#### 3.6.1 管理员管理
- 管理员列表：账号、姓名、角色、状态、最后登录、操作
- 新增/编辑：设置账号信息、分配角色

#### 3.6.2 角色管理
- 角色列表：名称、描述、权限数、操作
- 配置角色权限：菜单权限、按钮权限、数据权限

#### 3.6.3 权限管理
- 权限资源的增删改查
- 支持按模块分组管理

#### 3.6.4 系统设置
- 基础配置：站点名称、Logo、版权信息、备案号
- 存储配置（初期）：文件上传至本地目录 `E:\yinyu-music\resource`，按类型分目录存储（music、cover、avatar等），配置访问路径映射
- 存储配置（后期）：迁移至阿里云OSS，配置CDN加速、防盗链、水印
- 文件上传大小限制：音频 ≤ 200MB，封面 ≤ 5MB，头像 ≤ 2MB
- 音频配置：转码参数（FFmpeg）、音质选项（标准/高品质/Hi-Res）、音频切片策略

#### 3.6.5 操作日志
- 日志列表：操作人、模块、操作类型、请求参数、IP、时间
- 支持按条件筛选与导出

## 四、非功能需求

### 4.1 性能需求
- 页面首屏加载时间 ≤ 2秒
- 音频首包响应时间 ≤ 500ms
- 接口平均响应时间 ≤ 300ms
- 支持并发用户 ≥ 10,000

### 4.2 兼容性需求
- **浏览器**：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- **移动端**：iOS Safari、Android Chrome
- **分辨率**：支持1920×1080及以上，自适应1366×768
- **前端构建**：Vite 3.0+，支持ESM模块化

### 4.3 安全需求
- 用户密码加密存储（BCrypt）
- 接口防刷限制（Rate Limiting）
- 文件上传类型校验与病毒扫描
- SQL注入与XSS防护
- 敏感操作二次验证

### 4.4 可用性需求
- 界面文字清晰，对比度符合WCAG 2.1 AA标准
- 操作反馈明确，异常状态有提示
- 支持键盘快捷键操作

### 4.5 扩展性需求
- 模块化架构，支持功能插件化扩展
- 数据库设计预留扩展字段
- 接口版本化管理

## 五、数据需求

### 5.1 用户数据
- 基础信息：用户ID、昵称、头像、手机号、邮箱、密码、注册时间、状态
- 会员信息：会员等级、开通时间、到期时间、累计消费
- 行为数据：最近登录、播放时长、收藏数、下载数

### 5.2 内容数据
- 音乐：ID、名称、歌手、专辑、时长、文件URL（初期本地路径/后期OSS链接）、歌词、分类、标签、播放量、状态
- 歌单：ID、名称、封面、创建者、描述、标签、歌曲数、收藏数、播放量、状态
- 专辑：ID、名称、歌手、封面、发行日期、简介、歌曲数、播放量、状态
- 歌手：ID、姓名、头像、性别、地区、简介、粉丝数、歌曲数、状态

### 5.3 音频处理数据
- **转码记录**：ID、原始文件、目标格式、转码状态、耗时、错误信息
- **音质选项**：标准（128kbps MP3）、高品质（320kbps MP3）、Hi-Res（FLAC/ WAV）
- **FFmpeg参数**：编码格式、码率、采样率、声道数
- **异步任务（初期）**：Spring @Async任务队列，记录任务状态与执行日志
- **异步任务（后期）**：RabbitMQ消息队列，支持任务重试、失败告警、优先级调度

### 5.3 运营数据
- 轮播图：ID、标题、图片URL、链接、排序、状态、有效期
- 公告：ID、标题、内容、类型、置顶、发布时间、状态
- 活动：ID、名称、描述、规则、奖品、开始/结束时间、状态

### 6.1 术语表

| 术语 | 说明 |
|------|------|
| Hi-Res | 高解析度音频，指音质高于CD标准的无损音乐 |
| BGM | 背景音乐（Background Music） |
| FM | 调频广播，此处指个性化电台 |
| OSS | 对象存储服务（Object Storage Service） |
| JAVE2 | Java Audio Video Encoder 2，FFmpeg的Java封装库 |
| ESM | ECMAScript Modules，JavaScript模块化标准 |
| CDN | 内容分发网络（Content Delivery Network） |

### 6.2 技术约束

| 约束项 | 说明 |
|--------|------|
| **开发环境** | Node.js 18+，Java 17+，MySQL 8.0+ |
| **代码规范** | ESLint + Prettier（前端），Checkstyle（后端） |
| **API规范** | RESTful API，统一返回格式（code/data/message） |
| **版本控制** | Git，分支策略：main / develop / feature/* |
| **部署方式** | 初期单机部署，后期Docker容器化 + Nginx反向代理 |
